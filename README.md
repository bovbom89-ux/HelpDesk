# HelpDesk

Simple, professional ticket management for Discord.

HelpDesk helps Discord communities handle support requests through an organised, easy-to-use ticket system.

# Features

- Customisable ticket panels
- Private support channels
- Staff ticket claiming
- Add or remove ticket participants
- Close and reopen tickets
- Ticket transcripts
- Configurable support roles and categories
- Ticket activity logging

# Built for Every Community

Whether you're running a gaming community, a creator server, or a general Discord community, HelpDesk aims to make support easier for both members and staff.

# Project Status

HelpDesk is currently in development. Features may change as development progresses.

# Security

HelpDesk is designed with security in mind. Bot credentials and other sensitive information should always be stored securely and never committed to a public repository.
